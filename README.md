# Sharayu Ikhar Portfolio

A responsive eight-page portfolio website for Sharayu Ikhar, recreated from the supplied visual references.

## Tech stack

- React + Vite
- Tailwind CSS
- React Router DOM
- Framer Motion
- Lucide React

## Routes

- `/` — Home
- `/about` — About
- `/research` — Research
- `/publication` and `/publications` — Publication
- `/projects` — Projects
- `/media` — Media
- `/achievement` and `/achievements` — Achievement
- `/contact` — Contact

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The contact form provides client-side validation and a success state. It does not send data to a server.
